# 自主看盘台便携性说明

## 可实现的便携目标

| 项目 | 当前实现 |
|---|---|
| 目标系统 | Windows 10/11 x64，Intel/AMD |
| 安装要求 | 无需安装，无需目标电脑预装 Python |
| 机器绑定 | 不绑定用户名、盘符、安装目录或设备标识 |
| 应用数据 | 只写入程序文件夹内的 `data/` |
| 注册表 | 严格便携模式禁用开机启动入口，不写应用注册表配置 |
| 端口 | 首选 8765，被占用时依次尝试 8766–8775 |
| 浏览器 | Edge/Chrome 可用时优先用 InPrivate/无痕窗口打开 |
| API Key | 不随包分发，只从目标电脑环境变量读取 |
| 迁移 | 复制完整文件夹即可同时迁移程序与个人数据 |
| 干净分享 | 分享 ZIP 不包含制作者的状态、缓存、日志和备份 |

`portable.mode` 是便携构建标记。`自主看盘台.exe`、`_internal/`、`portable.mode`、`data/trading_calendar.json` 必须一起保留。程序需要在自身目录创建和更新 `data/state.json`、缓存、备份和日志，因此应解压到当前用户有写权限的位置。

## 无法承诺的绝对条件

“程序无机器绑定”和“操作系统完全零痕迹”是两件事。本项目能控制自身文件和注册表行为，不能阻止 Windows Defender、SmartScreen、事件日志、DNS 缓存、代理、防火墙、路由器或企业终端管理软件按各自策略记录程序和网络访问。无痕窗口可减少常规浏览历史，不等于系统级匿名或取证不可见。

“自动多源回退”和“任何网络必定有实时行情”也是两件事。程序会在可选 HiThink、腾讯和东方财富之间回退，并保留最近成功缓存；网络运营商、单位防火墙、地区策略、上游限流或接口变化仍可能使全部来源不可达。此时页面会明确显示缓存或失败，不会用模拟数据冒充实时行情。

当前构建没有商业代码签名，新电脑可能出现“未知发布者”或 SmartScreen 提示。Windows 7/8、Windows on ARM、32 位 Windows、只读目录和禁止运行未知 EXE 的企业电脑不在保证范围内。
