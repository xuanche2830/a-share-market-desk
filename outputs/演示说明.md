# 两分钟演示路径

这份演示用于向招聘方或项目评审快速说明产品目标和工程实现。演示前使用默认示例数据，不导入个人自选股、预警记录或 API Key。

## 0:00–0:20 项目定位

打开首页，说明这是 Windows 本地 A 股行情观察和规则预警工具。数据、规则和记录默认保存在本机；工具不连接券商，也不提供自动交易或收益预测。

## 0:20–0:45 搜索与行情

在搜索框输入“茅”“mt”或“600519”，展示名称片段、拼音简称和股票代码搜索。选择股票后说明价格、涨跌幅、数据来源、更新时间和交易时段状态。

## 0:45–1:10 指标与图表

切换 60/120/250 日范围，展示 K 线、成交量、MA、RSI 和 MACD。强调指标口径公开，缺失值、缓存数据和来源失败会明确显示。

## 1:10–1:35 预警与解释

使用模板创建 RSI、MACD 或突破放量规则，点击“立即测试”。说明试算不会写记录或发通知；正式检查支持冷却、每日一次、仅交易时段和安静时段。

## 1:35–1:55 历史回放与审计

点击规则回放，展示逐日事件和 1/5/20 个交易日后的历史样本。切换到审计区，说明系统会区分未命中、持续成立、时段跳过、冷却拦截、数据源失败和真实触发。

## 1:55–2:00 工程交付

展示 GitHub Actions 和测试结果，并说明项目有 58 项自动化测试、便携 Windows x64 分享包和多数据源降级。

## 建议展示顺序

1. 先讲问题和边界，再展示界面。
2. 重点演示一次搜索、一次规则试算和一次历史回放。
3. 最后打开 GitHub Actions，证明测试由远端环境自动运行。
4. 不宣称实时数据永远稳定，也不把历史样本解释成收益预测。
