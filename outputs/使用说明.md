# 自主看盘台 V2 使用说明

## 启动与停止

在本目录双击或用 PowerShell 运行：

```powershell
.\启动自主看盘台.ps1
```

浏览器会打开 `http://127.0.0.1:8765`。关闭浏览器只会关闭页面；要停止本地服务，请回到 PowerShell 按 `Ctrl+C`。

如果使用 `release\自主看盘台\自主看盘台.exe`，程序会驻留在 Windows 右下角通知区域，不显示黑色命令窗口。双击托盘图标打开页面；右键菜单可以暂停/恢复预警、打开日志目录或退出程序。关闭浏览器不会停止 EXE。

分享版是 Windows 10/11 x64 便携文件夹：完整解压到有写权限的位置，保留 `_internal` 和 `portable.mode`，双击 EXE 即可。程序不写注册表开机启动项，状态、缓存、备份和日志只写入同目录下的 `data\`。默认 8765 被占用时会自动尝试到 8775；Edge/Chrome 可用时优先打开无痕窗口。迁移时复制整个文件夹，不能只复制 EXE。

## 第一次使用

1. 左侧输入股票名称片段、拼音简称或代码，从候选列表点击添加。例如“茅台”“宁德”“gzmt”或“600519”都可以；仍支持直接输入完整 6 位代码。
2. 点击自选股查看前复权日 K、MA、RSI 和 MACD。
3. 在右侧选择价格、均线、突破、成交量、RSI、MACD 或“突破并放量”规则。新规则默认只在交易时段触发。
4. EXE 模式使用 Windows 原生通知，浏览器关闭后仍可弹出；页面会显示“Windows 通知已开启”。源码模式没有托盘时，仍可授权浏览器通知。

自选股卡片可编辑分组和备注；上方可以按分组筛选、按涨跌幅或名称排序。“批量导入”支持一次粘贴最多 50 个股票代码，用空格、逗号或换行分隔。

规则创建后可点“立即测试”。它会读取当前真实行情和最新已完成日 K，显示当前是否命中，但不会生成触发记录或通知。左侧可配置通知安静时段，默认 15:01–09:29；安静时段内命中仍保留记录，但不弹窗。触发记录页可按股票、规则和日期筛选，并把当前筛选结果导出为 CSV。

每条规则旁的“回放”会使用最多 750 根已完成日 K 逐日重算，列出历史事件和事件后 1、5、20 个交易日的样本统计。价格规则使用历史收盘价近似，无法还原盘中触碰；这些统计用于检查规则是否按预期工作，不代表胜率预测或投资建议。

右侧“审计统计”区会解释规则为什么没有通知：包括未命中、条件持续成立、非交易时段跳过、每日一次限制、冷却限制、数据源失败和静默触发。清空审计明细不会清零每条规则的累计检查和触发计数。

K 线下方“公司与市场背景”显示上证、深证、创业板指数和所选股票的公开市值、PE、PB、行业等字段。公司概况主来源失败时会降级到腾讯的部分字段，因此行业、地区、上市日期可能显示“—”，不会用猜测补齐。

已有规则可编辑、复制、暂停或删除；复制后的规则默认暂停，检查参数后再启用。快速模板会预填常用参数，但仍需由你确认并保存。

K 线工具栏可切换 60/90/120/250 日、显示或隐藏均线与预警标记。鼠标滚轮缩放，按住图表左右拖动可查看较早数据，“重置”回到最近区间。

开盘时可把刷新间隔设为“10 秒（开盘推荐）”。最新价和价格预警按该间隔检查，日 K、MA、RSI、MACD 最多每 60 秒更新一次，以降低公开数据源被限流的概率。“实时”指轮询更新，不是交易所逐笔行情。

如果源码模式下按钮显示“浏览器不支持通知”，请直接用普通 Chrome 或 Edge 打开本地地址；部分内置或自动化浏览器会移除通知能力。如果显示“通知权限已被拒绝”，请在浏览器的网站权限中重新允许 `127.0.0.1` 的通知。

## 看懂数据状态

- **实时请求成功**：本轮外部来源成功，可以检查预警。
- **缓存数据**：本轮来源失败，页面展示最近成功缓存；本轮不触发预警。
- **暂时失败**：来源失败且无缓存，页面不会生成模拟行情。
- **实际来源**：显示本轮真正返回数据的 HiThink、腾讯或东方财富。
- **市场状态**：2026 年使用上交所官方休市安排；未覆盖年份会明确显示为按工作日与北京时间估算。

展开“查看数据源健康与口径”可以看到每个来源最近成功、最近错误、耗时和熔断冷却时间。
点击“测试当前数据路由”会真实请求当前股票的一份报价和 10 根日 K，并显示路由、实际来源与耗时。交易时段内行情时间落后超过 3 分钟时，页面会主动提示检查来源。

## 可选 HiThink 官方来源

不配置 Key 时，“自动选择”仍使用公开来源。已有 Key 时，可在启动前设置当前 PowerShell 会话：

```powershell
$env:HITHINK_FINANCE_API_KEY = "你的 Key"
.\启动自主看盘台.ps1
```

Key 只应存入环境变量。不要把 Key 写进项目文件、截图、日志或聊天内容。官方服务的权限和费用以当前账户及官方文档为准。

## 数据与隐私

- 自选股、规则和记录：`data\state.json`
- 自动和手动备份：`data\backups\`（最多 20 份）
- 最近成功缓存：`data\cache\`
- 运行与错误日志：`data\logs\app.log`
- 以上路径均被 Git 忽略。
- 健康接口只返回相对日志路径，不暴露当前电脑用户名、盘符或安装路径。
- 电脑关机、休眠或程序退出时不会持续监测；只关闭浏览器不影响 EXE 后台预警。

左侧“备份、恢复与导入导出”可以手动备份、恢复旧状态以及导入/导出 JSON。恢复或导入会替换当前自选股、规则、设置和记录，界面会先确认，服务端还会自动保存替换前的数据。导出文件不包含 API Key。

技术指标与规则只描述历史数据关系，不预测收益，也不构成投资建议。

严格意义上的“系统零痕迹”和“任何网络都可用”无法保证。Windows Defender/SmartScreen、浏览器、DNS、代理、防火墙或路由器可能保存系统级记录；公开行情源也可能在某些网络被拦截或临时不可用。程序自身没有机器绑定，并会在 HiThink、腾讯和东方财富之间按配置回退、明确显示实际来源或失败原因。
