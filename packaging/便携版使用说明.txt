自主看盘台 Windows 便携版
==========================

启动
----
双击“自主看盘台.exe”。程序会启动本地服务，并自动打开浏览器：
http://127.0.0.1:8765

程序会在 Windows 右下角通知区域显示托盘图标，不再弹出黑色命令窗口。
双击托盘图标可以打开页面；右键菜单可以暂停/恢复预警、打开日志目录或退出程序。
关闭浏览器不会停止预警；需要完全停止时请在托盘菜单中点击“退出”。
支持 Windows 10/11 64 位 Intel 或 AMD 电脑；不支持 macOS、Linux 和 32 位 Windows。
不保证 Windows 7/8、ARM64 或受单位安全策略限制的电脑可以运行。

便携方式
--------
请完整解压后运行，不要只复制 exe，也不要删除 _internal 或 portable.mode。
程序不需要安装，不写注册表开机启动项，不绑定盘符、用户名或固定目录。
自选、规则、缓存、备份和日志都保存在当前文件夹的 data 目录；换电脑时复制整个文件夹即可。
请放在桌面、文档、U 盘等有写权限的位置，不要放入 Program Files 或只读目录。
8765 端口被占用时会自动尝试 8766 至 8775；Edge/Chrome 可用时优先打开无痕窗口。

数据
----
自选股、预警规则和触发记录保存在 data\state.json。
每次修改前的状态自动保存在 data\backups，最多保留 20 份。页面左侧可手动备份、恢复以及导入/导出 JSON；这些文件不包含 API Key。
自选股支持分组、备注、排序和批量代码导入。K 线支持区间切换、滚轮缩放、拖动查看和预警标记。
规则支持编辑、复制、筛选与快速模板；复制出来的规则默认暂停。
新建预警默认只在交易时段触发；左侧可设置通知安静时段。规则卡片的“立即测试”只用真实数据试算，不写记录、不发通知。
触发记录可按股票、规则和日期筛选，并导出当前筛选结果为 CSV。
运行日志保存在 data\logs\app.log，最多保留 4 个轮转文件。
分享版首次启动时会自动生成独立的 state.json，不包含制作者的个人自选和预警数据。
如需迁移到另一台 Windows 电脑，请复制整个“自主看盘台”文件夹。
本地自建 EXE 没有商业代码签名，复制到其他电脑后 Windows 可能显示“未知发布者”；可先用 SHA256.txt 核对文件完整性。

数据源
------
未配置 Key 时，程序自动使用腾讯/东方财富公开行情。
如需使用同花顺官方接口，请在启动程序前设置 Windows 用户环境变量：
HITHINK_FINANCE_API_KEY
程序沿用 Windows 当前网络和代理设置。公开来源可能被某些网络拦截、限流或临时关闭；程序会自动换源并显示错误，但不能保证任何网络都能取得实时行情。

边界
----
本工具用于行情观察、技术指标学习和确定性条件预警。
Windows 原生通知要求程序仍在运行；电脑关机、休眠或退出程序后不会继续监控。
不连接券商，不自动交易，不构成投资建议。
便携模式只能避免程序自身产生机器绑定和注册表配置；Windows、浏览器、安全软件、DNS、代理或路由器仍可能留下系统级记录。
